## How to Run

Make sure Java is installed on your system.

Check the Java version:

```bash
java --version
```

Compile a Java file:

```bash
javac FileName.java
```

Run the program:

```bash
java FileName
```

For example:

```bash
javac OOPSinPen.java
java OOPSinPen
```
